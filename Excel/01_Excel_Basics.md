# Excel Basics for Data Analysts

## What is Microsoft Excel?

Microsoft Excel is a spreadsheet application used to organize, analyze, clean, and visualize data. It is one of the most widely used tools by Data Analysts.

## Why Do Data Analysts Use Excel?

* Data Cleaning
* Data Validation
* Calculations
* Reporting
* Dashboard Creation
* Pivot Tables
* Quick Analysis

## Workbook vs Worksheet

| Workbook   | Worksheet        |
| ---------- | ---------------- |
| Excel File | Individual Sheet |

## Common Data Types

* Number
* Text
* Date
* Currency
* Percentage
* Boolean

## Frequently Used Shortcuts

* Ctrl + C → Copy
* Ctrl + V → Paste
* Ctrl + Z → Undo
* Ctrl + Shift + L → Filter
* Ctrl + Arrow Keys → Navigate Data
* Alt + = → AutoSum

## Key Skills Every Data Analyst Should Know

* Sorting
* Filtering
* Removing Duplicates
* Text to Columns
* Flash Fill
* Conditional Formatting
* Pivot Tables
* Charts

## Interview Question

**Q. Why is Excel still important for Data Analysts?**

**Answer:** Excel is fast, easy to use, and widely adopted across industries. It enables analysts to clean data, perform calculations, build reports, and create dashboards without requiring programming knowledge.
